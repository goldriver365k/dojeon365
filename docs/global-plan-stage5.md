# DigiStep365 글로벌 확장 — 5차 작업 보고 (2026-11-25)

## 완료 기능
1. **영어 연습 그림**: 국내 앱과 같은 그림 코드(`assets/screens.js`)에 번역 장치(`setTranslator`)를 넣어, 영어 페이지를 만들 때만 그림 속 글자를 영어로 바꿈
   - 단어표: `i18n/en/screen-terms.js`(One UI 영어 메뉴 이름)
   - 한 글자라도 한국어가 남는 그림은 영어 페이지에 **넣지 않음**(반쯤 번역된 그림 금지) → 글로만 안내
   - 해외용 그림에서는 홈 화면의 카카오톡 대신 YouTube, 한글 자판 대신 영어 자판
   - 표시된 곳(빨간 상자)을 누르면 다음 단계로 넘어감, 키보드는 ‘Next’ 버튼
   - 국내 앱 그림은 그대로(번역 장치를 쓰지 않음, 테스트로 확인)
2. **영어 페이지의 내 휴대폰 선택**(`/en/galaxy/#my-phone`)
   - 맨 위에 ‘먼저 기종·소프트웨어 버전 확인하는 방법’(설정 → About phone → 모델명 → Software information → One UI version) + 연습 수업 링크
   - 시리즈·기종·One UI 버전 고르기, 각각 ‘I don’t know’, ‘Use common instructions’
   - 수업 목록과 수업 화면에 Supported / Check needed / Not supported 표시(2차와 같은 판단 규칙)
3. **콘텐츠 현황 페이지**(`/admin/`, 읽기 전용, noindex, robots 차단): 수업별 영어 상태·그림 수·내용 층·지원 조건, 언어별 상태
