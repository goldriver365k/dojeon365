# 카카오톡 사용법 교육 (국내 전용) — 운영 안내

2026-11-27 구축. 기존 갤럭시 교육의 카드·검색·음성·관리 기능을 그대로 재활용한다.

## 한눈에
| 항목 | 내용 |
|---|---|
| 위치 | 국내 홈 두 번째 카테고리 ‘카카오톡 사용법’(노란색), 앱 주소 `#/kakaotalk`, 검색용 주소 `/learn/kakaotalk/<id>/` (기존 `/learn/` 체계 유지) |
| 목차 | 15개 대분류 · 162개 사용법 (`data/kakaotalk/catalog.json`) — 162개는 초기 목표, 검수 후 교체 가능 |
| 공개 | **실제 갤럭시 카카오톡 화면 캡처 + 검수 기록**을 모두 갖추고 상태가 ‘공개’인 수업만. 나머지는 목차에 ‘수업 준비 중’ |
| 해외 | 표시 안 함(메뉴·교육·검색·사이트맵·hreflang 모두 없음, 번역 대상 아님). 테스트로 확인 |
| 관리 | `/admin/kakaotalk/` |

## 파일
- `data/kakaotalk/catalog.json` — 원본(관리자 화면이 고침). 수업마다 카카오톡 앱 버전·안드로이드·One UI·갤럭시 모델·메뉴 경로·지원 기능·단계·이미지·출처·마지막 확인 날짜·검수자·업데이트 필요·변경 기록
- `images/kakaotalk/<수업id>/` — 실제 화면 캡처(관리자 화면에서 올림)
- `scripts/build-kakaotalk.mjs` — 공개 조건 검사, 앱 자료 `data/kakaotalk/public.js`(자동 생성)·관리자 화면 생성
- 정적 페이지는 `scripts/build-ko.mjs`가 공개 수업만 만든다(사이트맵·구조화 데이터·하단 독립 교육 안내 포함)

## 공개 상태
작성 중 → 이미지 확보·제작 중 → 검수 필요 → 검수 완료 → **공개** / 업데이트 필요(공개 유지, “화면이 바뀌었을 수 있어요” 안내) / 비공개

‘공개’로 바꾸려면(관리자 화면이 막고, 빌드가 한 번 더 검사):
- 카카오톡 앱 버전, 안드로이드 버전, 갤럭시 모델, 마지막 확인 날짜, 검수자, 공식 참고 자료
- 단계마다: 설명, 실제 화면 이미지(`images/kakaotalk/` 안), 이미지 설명(alt), 이미지 출처, 이미지 검수 날짜, **개인정보 노출 확인**

## 이미지 만드는 법 (필수)
1. 교육용 카카오계정·가상 이름·가상 대화로 최신 갤럭시 안드로이드 카카오톡을 실행해 **실제 화면을 캡처**한다. AI로 만든 화면·비슷하게 그린 화면은 쓰지 않는다.
2. 카카오 공식 자료([더 쉬운 카톡설명서](https://talktips.kakao.com/), [고객센터](https://cs.kakao.com/))와 메뉴 이름·순서를 대조한다. 공식 이미지는 사용 권한이 있을 때만.
3. 관리자 화면에서 단계에 캡처를 올리고, **그림을 눌러 누를 곳에 빨간 원**을 놓는다(화면 자체는 고치지 않음, 한 장 = 한 동작).
4. 실제 전화번호·계정·인증번호·비밀번호·결제 정보·실제 대화가 보이지 않는지 확인하고 체크한다.
5. 카카오톡 업데이트로 화면이 바뀌면 상태를 ‘업데이트 필요’로 바꾸고 이미지를 교체한 뒤 다시 검수한다.

## 주의 안내가 붙는 수업
결제·선물·환불, 인증서·전자문서, 계정·비밀번호·번호 변경, 나가기·삭제·차단, 백업·복원. 백업 수업에는 ‘대화 백업’과 ‘사진·동영상 백업’이 다르다는 안내가 붙는다(공개 전 고객센터 안내와 대조).

## 기존 그림 수업과의 관계
갤럭시 과정 13번 목차(카카오톡 설치·카톡 보내기·사진과 동영상·영상통화·단체방 알림)와 생활 디지털 `d00-kakao`(카카오톡 설치하기)는 **그린 연습 화면**(실제 카카오톡 화면 아님)이다. 관리자 화면에서 ‘기존 그림 수업과 겹침’으로 표시된다. 실제 화면 수업이 공개되면 교체·연결 여부를 정한다(지금은 그대로 둠).

## 방문 통계 (기존 GTM·GA4 재사용, 개인정보 없음)
앱이 dataLayer에 보내는 이벤트: `ds_lesson_start`, `ds_step_view`(step·steps), `ds_lesson_complete`, `ds_search`(search_term·results·kakaotalk_results). 모든 이벤트에 `course`(kakaotalk·galaxy·…)와 `lesson_id`.
- GTM: 트리거 ‘맞춤 이벤트’ 이름 `^ds_`(정규식) → 태그 ‘Google 애널리틱스: GA4 이벤트’, 이벤트 이름 `{{Event}}`, 매개변수 course·lesson_id·lesson_title·step·steps·search_term·results(데이터 영역 변수)
- GA4: 맞춤 측정기준으로 course·lesson_id·step 등록 → 탐색 분석에서 course = kakaotalk 필터
- 볼 수 있는 것: 일·주·월 방문자(보고서 기간), 인기 사용법(lesson_id별 ds_lesson_start), 많이 검색한 말(search_term), 시작·완료 횟수, 이탈 단계(ds_step_view의 마지막 step — 유입경로 탐색)
- 정적 페이지는 주소 `/learn/kakaotalk/`로 구분된다

## 앞으로 아이폰·PC
수업마다 `platform`(지금 `android`)이 있고 `meta.platforms`에 목록이 있다. 아이폰·PC 교육을 더할 때 같은 수업에 플랫폼별 단계를 추가하는 방식으로 넓힌다(이번에는 갤럭시 안드로이드만).
