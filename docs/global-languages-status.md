- 140 = 국내 갤럭시 수업 중 한국 전용 10개를 뺀 137개 + 해외용 새 수업 3개(13번 분류)
- 664단계 중 18단계는 해외용 새 수업이라 원본 그림이 없어 글로만 안내
- 언어 추가 방법: `i18n/<언어>/`에 `ui.js`·`galaxy.js`·`review.js`·`screen-terms.js`(+`from-en.js`), `i18n/device-strings.js`에 한 덩어리, `i18n/languages.js` 상태를 `draft`로 → `npm run build:global`
- 점검: 언어마다 단계 수 = 한국어 카드 수, 한 단계 한 문장, noindex, 그 언어 면책 문구, 영어와 hreflang 상호 연결, 그림 속 한글 없음, 모든 해외용 페이지 320px·아주 크게 가로 스크롤 없음
