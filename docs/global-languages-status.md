## 사람이 해야 할 일 (자동으로 할 수 없음)
1. **원어민 검수**: 관리자 편집 화면(`/admin/edit/`, 사용법 `docs/admin-editing.md`)에서 문장을 다듬고 검수 완료를 체크하면 noindex가 풀리고 사이트맵에 들어갑니다. 실제 그 언어로 설정한 갤럭시에서 메뉴 이름 대조가 가장 중요합니다.
2. **GA4·Search Console**: `i18n/site-config.js`에 측정 ID·인증 코드 입력(비어 있으면 꺼짐).
3. **도메인**: digistep365.com을 Netlify에 연결.
4. **관리자 편집**: `/admin/edit/` 완료. GitHub에 저장하려면 저장소 쓰기 권한(Contents: Read and write) 토큰이 필요합니다.
