# DigiStep365 글로벌 확장 — 7차 작업 보고 (2026-11-25)

## 완료 기능
1. **여러 언어 빌드 구조**: `scripts/build-global.mjs`를 언어별로 돌게 다시 짬
   - 언어마다 `i18n/<언어>/ui.js`(화면 문구 전부), `galaxy.js`(분류·제목·주소·단계), `review.js`(검수 기록), `screen-terms.js`(그림 속 단어)
   - 같은 수업이 있는 언어끼리 **hreflang 서로 연결**(+ x-default = 영어), 페이지 아래 언어 링크도 해당 언어 페이지로 바로 연결
   - 사이트맵은 검수된 페이지만, 검수된 언어끼리만 서로 연결
   - 관리 현황(`/admin/`)이 언어별 열로 바뀜(작성·검수·그림 수)
2. **스페인어 시범**(`/es/`): 화면 문구·22개 분류 전부, 01~03 목차 수업 18개(71단계), 연습 그림 71/71(스페인어 One UI 메뉴 이름), 스페인어 면책 문구·개인정보 안내. 아직 번역 안 된 수업은 목차에 ‘N lecciones más, próximamente’로 표시. 모두 초안(noindex)
3. **해외용 13번 분류 새 수업 3개**(영어, 국내 원본 없음 — 국내 13번은 카카오톡이라 해외용에서 빠짐)
   - Email photos with Gmail(7단계) · Send a video to family(6단계) · Make a video call with Google Meet(5단계)
   - Google 도움말 출처 링크, ‘실제 화면 확인 필요’ 안내, 연습 그림 없음(글로 안내)
   - 기존 수업과 겹치지 않게: 사진 첨부(문자)·여러 장 공유와 다른 내용
4. 360·320px ‘아주 크게’에서 아래 버튼(‘Siguiente’ 등) 글자가 잘리지 않게 수정
