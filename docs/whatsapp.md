# WhatsApp 교육 (해외 전용) — 운영 안내

2026-11-28 구축. 갤럭시·카카오톡 교육의 카드·관리·검색 구조를 재활용했다.

## 국가와 언어 구분 (`i18n/regions.js`)
| 사이트 | 국가(region) | 교육 |
|---|---|---|
| 한국어 `/` | KR | 갤럭시 + 카카오톡 (+ 국내 생활 과정) |
| 19개 언어 `/<언어>/` | GLOBAL | 갤럭시 + WhatsApp |

- 언어를 바꿔도 국가 설정의 교육만 보인다. 한국어 사이트에는 WhatsApp 교육, 해외 사이트에는 카카오톡 교육이 나오지 않는다(테스트로 확인).
- 해외 방문자용 한국어판은 만들지 않는다(작업지시서: 한국어 교육 버전 제작 안 함).

## 구성
- 목록 `data/whatsapp/catalog.json` — 15개 대분류, 160개 사용법(필수 50개 표시), 수업마다 주소(slug)·난이도(초급·중급·고급)·앱 버전·안드로이드·One UI·지원 국가·국가별 제한·메뉴 경로·출처·검수·언어별 번역(`i18n.<언어>`)
- 영어 원고 `data/whatsapp/lessons-en.mjs` — 필수 50개, 단계 카드 184장(한 카드 한 동작, 누를 곳 자동 검사)
- 화면 `assets/whatsapp-screens.js` — 코드로 그린 WhatsApp(안드로이드) 재현 화면: 채팅·업데이트·커뮤니티·통화 탭, 채팅방(첨부·선택·이모지·스티커·GIF·음성 녹음·반응), 설정 목록, 대화상자, 연락처 정보, 연락처 선택, 앨범, 미리보기(HD), 통화, 인증 양식, 검색, QR, 홈 화면, Play 스토어. 화면 글자는 모두 번역 함수(`setWaTranslator`)를 거치므로 언어별 화면으로 그릴 수 있고, 아랍어는 RTL 지원
- 빌드 `scripts/build-whatsapp.mjs` — 원고 채우기·검사, 언어별 공개 판단, 관리자 화면
- 관리 `/admin/whatsapp/` — 카카오톡 관리 화면과 같은 기능 + 언어별 진행률 표

## 공개 규칙
- 영어: 상태 ‘공개’ + 앱 버전·마지막 확인 날짜·검수자 + 모든 단계 검수 날짜
- 다른 언어: 위 조건 + 그 언어 번역(제목·모든 단계)과 번역 검수(`i18n.<언어>.status = published`)
- 공개 전 수업은 페이지·링크·사이트맵이 없다. 공개되면 `/<언어>/whatsapp/`(목차)와 `/<언어>/whatsapp/<slug>/`(수업)가 생기고, 해외 홈에 카드가 나오며, 언어 간 hreflang과 사이트맵에 들어간다.
- 각 WhatsApp 페이지 하단에 그 언어의 독립 교육 안내 문구(WhatsApp·Meta와 무관)를 표시한다.

## 공식 설치 경로 (설치 수업에 사용)
- https://www.whatsapp.com/download/android · Google Play `com.whatsapp` (개발자 WhatsApp LLC 확인 안내) · 고객센터 https://faq.whatsapp.com/
- 비공식 APK·변형 앱 안내 없음. 홈페이지가 앱을 설치하거나 휴대폰 언어를 바꾸지 않는다.

## 실제 화면 캡처
- 이 작업 환경에는 Android Studio·에뮬레이터·ADB·실제 갤럭시가 없고 KVM도 없어 자동 캡처를 할 수 없다. 전화번호 인증 우회는 하지 않는다.
- 실제 캡처를 쓰려면: 관리자 화면에서 단계마다 실제 화면을 올리고 빨간 원을 지정한다(카카오톡과 같은 방식, `images/whatsapp/`).
- 재현 화면으로 공개하려면: 실제 WhatsApp과 대조한 뒤 관리자 화면의 ‘실제 앱과 대조 완료 → 검수·공개’ 버튼.
