## 2차: 기종·One UI 선택(구현 완료)
- 주소 `#/device` → 시리즈 9개 → 기종 → One UI 버전(3.0~9.0 정식 버전만, 베타 제외)
- 강제 아님: 갤럭시 목차 위 ‘내 휴대폰’ 상자에서 고르거나 그냥 수업을 봄
- ‘내 휴대폰 기종을 모르겠습니다’, ‘이 중에서 내 기종을 모르겠습니다’, ‘One UI 버전을 모르겠습니다’, ‘공통 사용법으로 시작하기’, ‘기종·버전 확인하는 방법 보기’(기존 수업 g18-version 재사용)
- 이 기기 브라우저에만 저장(`device`), 사이트가 기종을 짐작해 정하지 않음
- 수업 목록에 지원 표시: **지원**(설명서로 확인) / **확인 필요**(다른 버전·확인 안 된 기종) / **지원하지 않음**(공식 근거가 있을 때만: Galaxy AI는 One UI 6.1 미만, S펜은 Ultra만, 삼성 파인드는 S24 시리즈부터)
- 카드 화면: 지원하지 않거나 확인이 필요하면 위쪽에 안내, ‘이 수업의 기준과 출처’에 ‘내 휴대폰’ 줄 추가
- 내용 층(A 공통/B 버전별/C 기종별/D 국가별)은 `meta.js`의 `layer`로 표시. 수업 파일은 고치지 않음
