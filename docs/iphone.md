## 구성
- 기종·iOS `data/iphone/models.js` — 41개 기종(6s~17 Pro Max·Air·16e, SE 1~3세대), iOS 15·16·17·18·26. 기종별 기능: 홈 버튼·Touch ID·Face ID·동작 버튼·카메라 컨트롤·다이내믹 아일랜드·Apple Intelligence·위성 긴급 구조·MagSafe·충전 단자(라이트닝/USB-C). 새 기종·새 iOS는 배열에 한 줄 추가.
- 목차 `data/iphone/outline.mjs` — 22개 대분류, 440개 사용법(한국어·영어 제목), 어르신 필수 100개(*).
- 단계 원고 `data/iphone/steps-essential.mjs` — 필수 100개(한국어·영어, 한 카드 한 동작, 캡처할 화면 메모). 홈 버튼 기종과 Face ID 기종의 순서가 다른 수업은 따로 씀.
- 필수 외 340개 `data/iphone/more-a.mjs`~`more-d.mjs`(모음 `more.mjs`) — 작성 도구 `data/iphone/dsl.mjs`로 메뉴 이름(영어)만 적으면 한국어·영어 단계 글과 단계별 그림이 함께 만들어짐. 화면 글자의 한국어는 `ko-screen.js`.
- 빌드 `scripts/build-iphone.mjs` — catalog 만들기·공개 판단·과정 첫 화면·수업 페이지·관리자 화면. `data/iphone/catalog.json`은 빌드가 원고로 채우고, 사람이 고친 수업·이미지가 있는 수업은 덮어쓰지 않음.
- 내 아이폰 선택 `assets/iphone-device.js` — 모델·iOS 선택(모델에 맞는 iOS만), 모를 때 확인 방법, 공통 사용법으로 시작, 기종에 없는 수업은 흐리게. 이 브라우저에만 저장(localStorage).
- 관리 `/admin/iphone/` — 카카오톡·WhatsApp 관리 화면과 같은 프로그램(`assets/admin-kakao.js`)에 아이폰 설정 추가: 아이폰 모델·iOS 버전, **편집 언어(한국어/영어)별 실제 화면 업로드**, 이미지 기록(기종·iOS·화면 언어·국가·캡처일·검수일·사용 권한·개인정보 확인), GitHub 저장.

## 공개 규칙 (작업지시서 8·17항)
- 실제 아이폰 화면 캡처만 공개한다. 출처가 `직접 캡처(교육용 아이폰)`, `Xcode iOS 시뮬레이터 캡처`, `사용 권한을 받은 Apple 공식 이미지` 중 하나여야 하고, 코드로 그린 화면·AI 생성 화면은 공개 조건을 통과하지 못한다.
- 언어마다 그 언어로 설정한 아이폰 화면이 따로 필요하다(`images/iphone/ko/…`, `images/iphone/en/…`).
- 공개 전 수업: 목차에 ‘준비 중’, 수업 페이지·사이트맵 없음. 공개 수업이 하나도 없으면 과정 첫 화면은 `noindex`(사이트맵 제외).
- 주의 문구: 초기화·계정 변경·사진 삭제·백업/복원·Apple Pay·위치 공유·긴급 구조 요청.
- 면책 문구(Apple 비제휴)를 과정 페이지 하단에 그 언어로 표시.

## 2026-11-28 운영자 결정: “직접 실제와 같이 만들어라”, “준비 중도 모두 완성하자”

- 공개 조건: 수업에 운영자 승인 표시(`approvedWithoutCompare`)와 이미지 출처 ‘원본 화면 기준 재현(운영자 승인)’이 있을 때만 그림으로 공개. 수업마다 “아이폰 화면을 보고 그린 그림이라 실제와 조금 다를 수 있어요” 안내.
- Apple 아이콘·로고 그림은 복제하지 않고 색과 단순한 모양으로만 나타냄. Face ID 기종(iPhone 16 기준)과 홈 버튼 기종(SE 3세대 기준) 그림을 구분.
- 실제 캡처를 올리면 그 단계는 캡처가 우선 쓰인다(관리자 화면에서 교체).

## 실제 화면 확보 방법
이 작업 환경(리눅스 클라우드)에는 Mac·Xcode·실제 아이폰이 없어 캡처할 수 없다. 운영자가 할 일:
1. 교육용 아이폰(가상 이름·가상 연락처)에서 화면을 캡처한다(옆 버튼 + 음량 높이기). 단계 카드의 ‘캡처할 화면’ 메모를 참고.
2. `/admin/iphone/`에서 수업을 고르고 단계마다 캡처를 올린 뒤 그림을 눌러 빨간 원 위치를 정한다.
3. 이미지 기록(기종·iOS·사용 권한=‘직접 캡처’)과 개인정보 확인을 채우고 ‘실제 앱과 대조 완료 → 검수·공개’를 누른 뒤 GitHub에 저장한다.
4. 영어 화면은 아이폰 언어를 English로 바꿔 같은 방법으로 ‘편집 언어: English’에서 올린다.
- Mac이 있으면 Xcode iOS 시뮬레이터(기종·iOS·언어 설정)로 캡처해도 된다. 전화·카메라·Face ID·결제 화면은 실제 기기로.
