Mi móvil

Sin elegir · instrucciones generales

Primero, busca el modelo y la versión de software de tu móvil
  1. Toca la aplicación Ajustes.
  2. Toca Acerca del teléfono, abajo del todo.
  3. Mira el nombre del modelo arriba (por ejemplo, Galaxy S26 · SM-S942N).
  4. Toca Información de software.
  5. Mira la versión de One UI (por ejemplo, 9.0).

En algunos modelos el menú se llama ‘Acerca del dispositivo’. También puedes escribir ‘Acerca del teléfono’ en la búsqueda de Ajustes.

Elegir es opcional. Solo se guarda en este navegador y nunca adivinamos tu modelo.
