Non scelto · istruzioni generali

Scegli il mio telefono

1. Inizia con le istruzioni generali

2. Scegli il mio telefono

Prima trova il modello e la versione software del telefono
  1. Tocca l’app Impostazioni.
  2. Tocca Info sul telefono, in fondo.
  3. Guarda il nome del modello in alto (per esempio Galaxy S26 · SM-S942N).
  4. Tocca Informazioni software.
  5. Guarda la versione One UI (per esempio 9.0).

Su alcuni modelli il menu si chiama ‘Info sul dispositivo’. Puoi anche scrivere ‘Info sul telefono’ nella ricerca delle Impostazioni.
