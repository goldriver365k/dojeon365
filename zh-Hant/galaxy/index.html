先查一查您手機的機型和軟體版本
  1. 輕觸設定應用程式。
  2. 輕觸最下面的關於手機。
  3. 看上方的型號名稱（例如 Galaxy S26 · SM-S942N）。
  4. 輕觸軟體資訊。
  5. 看One UI 版本（例如 9.0）。

部分機型的選單名稱是「關於裝置」。也可以在設定的搜尋框中輸入「關於手機」。
