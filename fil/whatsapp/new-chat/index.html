Magsimula ng bagong chat

Mga drowing ng screen ng WhatsApp ang mga larawang ito. Maaaring bahagyang iba ang pangalan at puwesto ng mga menu sa totoong app.

  1. Hakbang 1 ng 3

    Sa screen ng Mga Chat, i-tap ang berdeng button ng bagong chat.

  2. Hakbang 2 ng 3

    I-tap ang taong gusto mong padalhan ng mensahe.

  3. Hakbang 3 ng 3

    Bubukas ang chat. Mag-type sa message box sa ibaba.
