First, find your phone’s model and software version
  1. Tap the Settings app.
  2. Tap About phone at the very bottom.
  3. Check the model name at the top (for example, Galaxy S26 · SM-S942N).
  4. Tap Software information.
  5. Check the One UI version (for example, 9.0).

On some models the menu is called ‘About device’. You can also type ‘About phone’ in the Settings search.
