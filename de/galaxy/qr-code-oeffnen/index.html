Einen QR-Code öffnen

Öffnen Sie einen QR-Code mit der Galaxy-Kamera.

Geschrieben für Galaxy S26 · One UI 9 · Android 17. Menünamen können bei anderen Modellen und Versionen abweichen.

  1. Schritt 1 von 3

    Tippen Sie auf die App ‘Kamera’.

    Wenn sie nicht auf dem Startbildschirm ist, wischen Sie nach oben und suchen Sie sie im Apps-Bildschirm.

  2. Schritt 2 von 3

    Richten Sie die Kamera auf den QR-Code.

    Im Fotomodus den Code in die Bildmitte halten.

  3. Schritt 3 von 3

    Tippen Sie auf den gelben Link auf dem Bildschirm.

    Vorsicht bei QR-Codes von unbekannten Orten.
