Fotos per E-Mail mit Gmail senden

Senden Sie Fotos mit der Gmail-App per E-Mail an Ihre Familie.

Geschrieben für Galaxy S26 · One UI 9 · Android 17. Menünamen können bei anderen Modellen und Versionen abweichen.

Neue Lektion für die internationale Seite. Die Bildschirme von Google-Apps ändern sich oft; bitte am echten Handy prüfen.

  1. Schritt 1 von 7

    Tippen Sie auf die App ‘Gmail’.

    Wenn sie nicht auf dem Startbildschirm ist, wischen Sie nach oben und suchen Sie sie im Apps-Bildschirm.

  2. Schritt 2 von 7

    Tippen Sie unten rechts auf ‘Schreiben’.

  3. Schritt 3 von 7

    Geben Sie die E-Mail-Adresse der Person in das Feld ‘An’ ein.

  4. Schritt 4 von 7

    Tippen Sie oben auf die Büroklammer (Anhängen).

  5. Schritt 5 von 7

    Tippen Sie auf das Foto, das Sie senden möchten.

    Sie können mehrere Fotos antippen.

  6. Schritt 6 von 7

    Geben Sie einen kurzen Betreff ein.

  7. Schritt 7 von 7

    Tippen Sie oben auf Senden (Papierflieger).

Gut gemacht! Sie haben diese Lektion beendet. Weiter mit: Ein Video an die Familie senden
