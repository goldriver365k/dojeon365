Фото по почте через Gmail

Отправьте фото семье по электронной почте через приложение Gmail.

Написано для Galaxy S26 · One UI 9 · Android 17. На других моделях и версиях названия меню могут отличаться.

Новый урок для международного сайта. Экраны приложений Google часто меняются — проверьте на настоящем телефоне.

  1. Шаг 1 из 7

    Нажмите приложение «Gmail».

    Если его нет на главном экране, проведите вверх и найдите его на экране приложений.

  2. Шаг 2 из 7

    Нажмите «Написать» справа внизу.

  3. Шаг 3 из 7

    Введите адрес электронной почты в поле «Кому».

  4. Шаг 4 из 7

    Нажмите скрепку (Прикрепить) вверху.

  5. Шаг 5 из 7

    Нажмите фото, которое хотите отправить.

    Можно нажать несколько фото.

  6. Шаг 6 из 7

    Введите короткую тему.

  7. Шаг 7 из 7

    Нажмите кнопку «Отправить» (бумажный самолётик) вверху.
