# 편한자판 시니어 교육 플랫폼

갤럭시를 처음 쓰는 어르신이 도움 없이 휴대폰을 조작할 수 있도록, 삼성전자 공식 사용 설명서를 바탕으로 **한 카드에 동작 하나씩** 따라 하는 모바일 웹앱입니다.

- 홈: 카테고리 5개(1번 ‘갤럭시 휴대폰 사용방법’ 제공, 나머지 4개는 ‘준비 중’)
- 갤럭시 휴대폰 사용방법: 22개 목차(기초·생활·응용·고급 및 문제 해결), 세부 수업 147개, 카드 695장
- 빌드 도구·외부 라이브러리 없음. 정적 파일만으로 동작(Node.js 18+는 미리보기·테스트용)
- 진행 상황·글씨 크기는 이 기기의 브라우저 저장소에만 저장하고, 서버로 보내지 않음

## 실행

```bash
npm start
```

→ http://127.0.0.1:4180/

배포는 저장소 폴더를 그대로 정적 호스팅(Netlify, GitHub Pages 등)에 올리면 됩니다. 주소는 해시(`#/galaxy`) 방식이라 서버 설정이 따로 필요 없습니다.

## 테스트

```bash
npm test
```

수업 데이터 점검: 22개 목차·목차별 수업 수, 카드마다 안내 문장 하나(동작 두 개를 이어 쓴 문장 금지), 대체 텍스트, 연습 화면의 누를 곳이 그림에 실제로 있는지, 출처 링크, 첫 수업 네 장.

```bash
npm run test:e2e
```

브라우저 점검(Playwright/Chromium): 147개 수업 전부를 첫 카드부터 ‘완료’까지 진행(360px·‘아주 크게’에서 카드마다 가로 스크롤 확인), 연습 화면 누르기·길게 누르기·밀기·키보드, 이어서 하기, 음성 듣기, 검색, 320px 화면. 결과는 `docs/test-report.md`, 화면은 `docs/screenshots/`.

## 화면과 주소

| 주소 | 화면 |
|---|---|
| `#/` | 홈(카테고리 5개) |
| `#/galaxy` | 22개 목차 + 이어서 하기(필요할 때만) + 생활 표현 검색 |
| `#/galaxy/01` | 목차의 세부 수업 목록 |
| `#/lesson/g01-power/start` | 실제 휴대폰 실습 전 ‘다시 켜는 방법’ 안내(해당 수업만) |
| `#/lesson/<수업id>/<n>` | 카드 n번째 |
| `#/lesson/<수업id>/done` | 완료(다시 배우기 · 수업 목록으로) |

카드 화면(위→아래): 수업 제목 → ‘N단계 중 M단계’ → 큰 동작 안내 한 문장 → 누를 곳이 표시된 연습 화면 → ‘음성으로 듣기’ → 맨 아래에 고정된 ‘이전 / 다음(마지막은 완료)’.

- 연습 화면에서 맞는 곳을 누르면(또는 길게 누르기·밀기를 하면) 다음 카드로 넘어가고, 다른 곳을 누르면 같은 카드에서 다시 알려 줍니다.
- 실제 휴대폰에서 할 동작은 직접 하고 ‘다음’을 누릅니다. 옆으로 밀지 않아도 버튼만으로 모든 단계를 이동할 수 있습니다.
- 카드를 열 때마다 위치를 저장합니다. 카드에 `resumeAt`이 있으면 그 카드를 이어볼 위치로 저장합니다(예: 전원 끄기 직전 카드 → 다시 켠 뒤 확인 카드).

## 파일 구조

```
index.html                  앱 껍데기

assets/screens.js           연습용 휴대폰 화면 그림(SVG)과 누를 곳 위치
assets/apps.js              앱 이름(화면 이름·공식 이름)과 아이콘 그림, 설정 메뉴 아이콘
assets/app.css              공통 디자인(글씨 크기 3단계, 색, 버튼)
data/categories.js          홈 카테고리 5개
data/galaxy/helpers.js      카드 만드는 도구, 설정 메뉴 이름(공식 설명서 기준), 출처
data/galaxy/ch01-06.js      [기초] 01~06
data/galaxy/ch07-13.js      [생활] 07~13
data/galaxy/ch14-22.js      [응용] 14~18, [고급 및 문제 해결] 19~22
data/galaxy/index.js        목차 구분과 수업 찾기
scripts/serve.js            미리보기 서버

```

공통 디자인(`app.css`, `screens.js`, `app.js`)을 고치면 모든 카드에 반영됩니다. 수업 내용이나 사진만 바꿀 때는 해당 목차 데이터 파일만 고칩니다.

## 수업 데이터 고치기

수업 하나:

```js
lesson('g03-font', '글씨 크게 보기', {
  q: ['글씨가 작아요', '글자 크게'],          // 생활 속 검색어
  src: [M(96, '디스플레이 · 글자 크기와 스타일')], // 공식 출처(설명서 쪽)
  models: 'S펜: 갤럭시 S26 Ultra…',            // 기종 전용 기능일 때만
  check: '실제 화면 확인 필요 내용',             // 확인이 덜 된 부분이 있을 때만
  caution: PRACTICE_ONLY,                       // 결제·보안처럼 실제 결과가 생기는 수업
  cards: [ ...path('디스플레이', '글자 크기와 스타일'), /* 카드들 */ ],
})
```

기준 기종·소프트웨어·확인 날짜는 `helpers.js`의 `BASE`(갤럭시 S26 SM-S942N, One UI 9 · Android 17)를 따르고, 수업에 `model`·`software`를 넣으면 그 수업만 바뀝니다.

카드 한 장(동작 하나):

| 항목 | 뜻 |
|---|---|
| `text` | 안내 문장 하나. ‘설정을 열고 디스플레이를 누르세요’처럼 두 동작이면 카드 두 장으로 나눕니다(테스트가 막음). 두 버튼을 동시에 누르는 동작은 한 장. |
| `screen` | 연습 그림 종류와 내용(`list`, `home`, `side`, `dialog`, `keypad`, `camera`, `gallery`, `chat`, `keyboard`, `shade` 등) |
| `photo` | 실제 사진. 있으면 그림 대신 씀 |
| `alt` | 그림 설명(보조 기술이 읽음) |
| `target` | 누를 곳 이름(그림 속 이름과 같아야 함) |
| `action` | `tap`, `hold`, `swipe-up/down/left/right`, `self`(실제 휴대폰에서 직접) |
| `done` | 완료 조건: `practice`(연습 화면에서 맞게 하기) / `self`(직접 하고 ‘다음’) — 자동으로 정해짐 |
| `hint`, `note` | 보조 설명 / 기종·버전에 따라 다른 점 |

자주 쓰는 도구: `app('설정')`, `path('디스플레이', '글자 크기와 스타일')`(설정 → 각 메뉴 카드를 한 장씩), `menu(부모, 항목)`, `tap(이름, 화면)`, `toggle(화면 제목, 스위치 이름)`, `hold(이름, 화면)`, `swipe('up', 문장, 화면)`, `self(문장)`, `look(문장, 화면)`.

## 앱 이름과 아이콘

- 앱 목록은 `assets/apps.js` 한 곳에서 관리합니다. 안내 문장, 연습 화면의 아이콘, 카드의 ‘앱 이름표’가 모두 여기서 이름과 그림을 가져옵니다.
- 안내 문장에는 **휴대폰 화면에 보이는 이름**을 씁니다. 삼성 앱은 사용 설명서가 부르는 이름을 따릅니다(예: Galaxy Store → ‘스토어’, 삼성 노트 → ‘노트’, 삼성 인터넷 → ‘브라우저’, Google Play → ‘Play 스토어’).
- 앱을 여는 카드에는 아이콘 + 화면에 보이는 이름 + 공식 이름을 함께 표시합니다.
- 예전 이름으로 적어도 `app('삼성 노트')`처럼 자동으로 화면 이름(‘노트’)으로 바뀝니다. 목록에 없는 앱을 쓰면 데이터 점검이 실패합니다.
- 아이콘은 실제 앱 아이콘의 색과 모양을 본뜬 연습용 그림입니다. 전체 목록: `docs/app-names.md`

## 사진 바꾸기

연습 그림 자리에 실제 사진을 넣으려면 카드에 `photo`를 더합니다. 누를 곳은 사진 크기에 대한 %로 적습니다.

```js
tap('측면 버튼', SIDE, {
  text: '그림에서 측면 버튼을 누르세요.',
  photo: { src: 'images/s26-side.jpg', alt: '갤럭시 S26 오른쪽 옆면 사진. 측면 버튼에 빨간 테두리', target: { x: 82, y: 44, w: 10, h: 10 } },
}),
```

바꿀 카드 목록은 `node scripts/image-list.mjs`로 다시 만들 수 있습니다(`docs/image-replacement.md`). 개인정보가 없는 캡처와 직접 찍은 사진을 우선 쓰고, 삼성 공식 이미지는 사용 조건을 확인한 경우에만 씁니다.

## 출처와 확인 기준

- 삼성전자 갤럭시 S26 시리즈 사용 설명서(Android 17, Rev.1.0, 2026년 9월, 한국어) — 삼성전자 고객지원 SM-S942N 페이지의 매뉴얼
- 수업마다 관련 설명서 쪽 링크(`…pdf#page=쪽`)와 기준 기종·소프트웨어·확인 날짜를 카드 아래 ‘이 수업의 기준과 출처’에 표시
- 설명서에 없는 앱(카카오톡·편한자판·Google 지도 등)과 화면 이름이 확실하지 않은 부분은 수업에 `check`로 표시 → 실제 화면으로 확인 후 지우면 됩니다

## 해외용 영어 사이트(DigiStep365)

- 주소: `/en/`(홈), `/en/galaxy/`(22개 분류), `/en/galaxy/<영어 주소>/`(수업마다 실제 페이지). 국내 주소(`/#/…`)는 그대로
