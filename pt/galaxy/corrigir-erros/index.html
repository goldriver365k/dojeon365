Corrigir erros de digitação

Corrija erros com a tecla de apagar e mudando o cursor de lugar.

  1. Passo 1 de 3

    Toque uma vez na tecla de apagar (⌫).

    Apaga a letra logo antes do cursor.

  2. Passo 2 de 3

    Digite a letra certa.

  3. Passo 3 de 3

    Para corrigir uma letra no meio, toque nesse lugar.

    O cursor (o tracinho que pisca) vai para onde você tocou.

Escrito para Galaxy S26 · One UI 9 · Android 17. Os nomes dos menus podem mudar em outros modelos e versões.
