Atender ou recusar uma chamada

Atenda deslizando o botão verde, recuse com o vermelho ou recuse com uma mensagem.

Escrito para Galaxy S26 · One UI 9 · Android 17. Os nomes dos menus podem mudar em outros modelos e versões.

  1. Passo 1 de 3

    Toque e segure o botão verde de atender e deslize para cima.

    Tire do círculo para atender.

  2. Passo 2 de 3

    Para recusar, toque e segure o botão vermelho e deslize para cima.

  3. Passo 3 de 3

    Para recusar com mensagem, deslize para cima ‘Enviar mensagem’, embaixo.

    Escolha uma mensagem e ela é enviada para quem ligou.

    Bom saber Em Configurações → Acessibilidade → Interação e destreza você pode atender com um só toque.
