Mengusap untuk berpindah

Usap untuk berpindah halaman Beranda dan membuka layar Aplikasi.

  1. Langkah 1 dari 3

    Usap layar ke kiri.

    Anda pindah ke halaman Beranda berikutnya.

  2. Langkah 2 dari 3

    Usap dari bawah ke atas di layar Beranda.

    Layar Aplikasi dengan semua aplikasi terbuka.

  3. Langkah 3 dari 3

    Usap ke bawah di layar Aplikasi.

    Anda kembali ke layar Beranda.
