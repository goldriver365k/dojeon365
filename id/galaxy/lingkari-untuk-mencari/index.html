Mencari hal di layar

Cari sesuatu di layar dengan melingkarinya memakai Lingkari untuk Mencari.

Ditulis untuk Galaxy S26 · One UI 9 · Android 17. Nama menu bisa berbeda pada model dan versi lain.

  1. Langkah 1 dari 3

    Sentuh dan tahan tombol Beranda di bawah layar.

  2. Langkah 2 dari 3

    Gambar lingkaran dengan jari di sekitar yang ingin dicari.

  3. Langkah 3 dari 3

    Baca hasil pencarian di bawah.

    Perlu diketahui Bixby Vision tersedia di seri Galaxy S25, S24, dan S23. S26 memakai cara ini (Lingkari untuk Mencari).
