  1. 1단계 / 4

    문자 속 링크(주소)는 누르지 마세요.

  2. 2단계 / 4

    링크를 누르면 가짜 앱이 깔리거나 가짜 상담원에게 연결돼요.

  3. 3단계 / 4

    택배는 택배 회사 앱, 과태료는 공식 누리집에서 직접 확인하세요.

  4. 4단계 / 4

    헷갈리는 문자는 118(한국인터넷진흥원)에 물어보세요.
