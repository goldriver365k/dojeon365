이렇게도 찾아요 인증번호본인인증 번호신분증 사진명의 도용

  1. 1단계 / 3

    “인증번호를 불러 달라”고 하면 절대 알려 주지 마세요.

    인증번호를 알려 주면 내 이름으로 휴대폰 개통·대출이 될 수 있어요.

  2. 2단계 / 3

    신분증 사진이나 통장 사진도 보내지 마세요.

  3. 3단계 / 3

    명의 도용이 걱정되면 엠세이퍼(M-Safer)에서 내 이름으로 개통된 휴대폰을 확인하세요.

연습 화면은 실제 앱과 조금 다를 수 있어요. 돈이 나가거나 비밀번호가 필요한 일은 연습 화면에서만 해요.
