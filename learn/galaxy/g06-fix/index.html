  1. 1단계 / 3

    지우기 버튼(⌫)을 한 번 누르세요.

    커서 바로 앞 글자가 지워져요.

  2. 2단계 / 3

    바른 글자를 다시 적으세요.

  3. 3단계 / 3

    가운데 글자를 고치려면 고칠 곳을 누르세요.

    누른 곳으로 커서(깜빡이는 막대)가 옮겨가요.

기준: 갤럭시 S26 (SM-S942N) · One UI 9 · Android 17. 기종과 버전에 따라 메뉴 이름이 조금 다를 수 있어요.
