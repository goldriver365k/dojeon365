이렇게도 찾아요 디바이스 케어휴대폰 점검느려요최적화청소

  1. 1단계 / 3

    ‘설정’ 앱을 누르세요.

    홈 화면에 없으면 화면을 위로 밀어 앱스 화면에서 찾으세요.

  2. 2단계 / 3

    ‘디바이스 케어’를 누르세요.

    안 보이면 화면을 위로 밀어 찾으세요.

  3. 3단계 / 3

    ‘지금 최적화’를 누르세요.

    쓰지 않는 앱을 정리하고 점검해 줘요.
