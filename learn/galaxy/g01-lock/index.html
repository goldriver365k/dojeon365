이렇게도 찾아요 화면 끄기잠금잠금 풀기화면 켜기

  1. 1단계 / 3

    측면 버튼을 한 번 짧게 누르세요.

    화면이 꺼지면서 자동으로 잠겨요.

  2. 2단계 / 3

    측면 버튼을 다시 짧게 누르세요.

    잠금화면이 켜져요. 화면을 두 번 눌러도 켜져요.

  3. 3단계 / 3

    화면을 위로 미세요.

    PIN이나 지문을 정해 두었다면 그것으로 잠금을 풀어요.
