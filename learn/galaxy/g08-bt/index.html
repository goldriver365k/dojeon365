이렇게도 찾아요 블루투스무선 이어폰버즈이어폰 연결스피커 연결

  1. 1단계 / 7

    이어폰을 연결 모드로 켜세요.

  2. 2단계 / 7

    ‘설정’ 앱을 누르세요.

    홈 화면에 없으면 화면을 위로 밀어 앱스 화면에서 찾으세요.

  3. 3단계 / 7

    ‘연결’을 누르세요.

    안 보이면 화면을 위로 밀어 찾으세요.

  4. 4단계 / 7

    ‘블루투스’를 누르세요.

    안 보이면 화면을 위로 밀어 찾으세요.

  5. 5단계 / 7

    ‘블루투스’ 스위치를 눌러 켜세요.

  6. 6단계 / 7

    목록에서 내 이어폰 이름을 누르세요.

  7. 7단계 / 7

    ‘연결’을 누르세요.

기준: 갤럭시 S26 (SM-S942N) · One UI 9 · Android 17. 기종과 버전에 따라 메뉴 이름이 조금 다를 수 있어요.
