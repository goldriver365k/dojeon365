이렇게도 찾아요 전화 걸기전화하기번호 누르기키패드

  1. 1단계 / 5

    ‘전화’ 앱을 누르세요.

    홈 화면에 없으면 화면을 위로 밀어 앱스 화면에서 찾으세요.

  2. 2단계 / 5

    아래쪽 ‘키패드’를 누르세요.

  3. 3단계 / 5

    전화번호 숫자를 차례로 누르세요.

    잘못 누르면 오른쪽 아래 지우기 버튼으로 지워요.

  4. 4단계 / 5

    초록색 통화 버튼을 누르세요.

  5. 5단계 / 5

    통화를 마치면 빨간 통화 종료 버튼을 누르세요.
