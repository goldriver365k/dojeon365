  1. 1단계 / 5

    화면 오른쪽 위를 아래로 미세요.

    빠른 설정창이 열려요. 왼쪽 위를 밀면 알림창이 열려요.

  2. 2단계 / 5

    ‘비행기 탑승 모드’가 켜져 있으면 눌러 끄세요.

  3. 3단계 / 5

    ‘모바일 데이터’가 꺼져 있으면 눌러 켜세요.

  4. 4단계 / 5

    신호가 약하면 다른 장소로 옮겨 보세요.

  5. 5단계 / 5

    그래도 안 되면 휴대폰을 다시 시작하세요.
