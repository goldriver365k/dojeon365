Ajouter de nouveaux autocollants

Ces images sont des dessins de l’écran de WhatsApp. Le nom et la place des menus peuvent être un peu différents dans la vraie application.

  1. Étape 1 sur 5

    Dans l’écran Discussions, appuyez sur la discussion avec Maria.

  2. Étape 2 sur 5

    Appuyez sur le visage souriant dans la zone de message.

  3. Étape 3 sur 5

    Appuyez sur « Autocollants ».

  4. Étape 4 sur 5

    Appuyez sur le « + » pour voir plus de packs d’autocollants.

  5. Étape 5 sur 5

    Appuyez sur « Ajouter » à côté d’un pack qui vous plaît.

Bravo ! Vous avez terminé cette leçon. Suivante : Gérer les autocollants favoris
