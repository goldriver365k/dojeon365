Activer le haut-parleur pendant un appel

Activez le haut-parleur pendant un appel pour parler sans tenir le téléphone à l’oreille.

Écrit pour Galaxy S26 · One UI 9 · Android 17. Les noms des menus peuvent différer sur d’autres modèles et versions.

  1. Étape 1 sur 3

    Passez ou recevez un appel.

  2. Étape 2 sur 3

    Touchez ‘Haut-parleur’.

    Vous entendez et parlez avec le téléphone loin de l’oreille.

  3. Étape 3 sur 3

    Pour l’arrêter, touchez de nouveau ‘Haut-parleur’.

Bravo ! Vous avez terminé cette leçon. Suivante : Rappeler un appel manqué
