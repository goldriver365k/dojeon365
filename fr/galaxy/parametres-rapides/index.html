Ouvrir le volet des paramètres rapides

Ouvrez le volet des paramètres rapides et découvrez ses boutons.

  1. Étape 1 sur 4

    Balayez vers le bas depuis le coin supérieur droit de l’écran.

    Le volet des paramètres rapides s’ouvre. Depuis le coin supérieur gauche, ce sont les notifications.

  2. Étape 2 sur 4

    Regardez les boutons du volet.

    Les boutons bleus sont activés. Touchez un bouton pour l’activer ou le désactiver.

  3. Étape 3 sur 4

    Maintenez appuyé le bouton ‘Wi-Fi’.

    Maintenir ouvre ses réglages détaillés.

  4. Étape 4 sur 4

    Balayez vers le haut pour fermer le volet.

Écrit pour Galaxy S26 · One UI 9 · Android 17. Les noms des menus peuvent différer sur d’autres modèles et versions.
