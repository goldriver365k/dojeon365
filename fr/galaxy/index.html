Choisir mon téléphone

1. Commencer avec les instructions générales

2. Choisir mon téléphone

D’abord, trouvez le modèle et la version logicielle de votre téléphone
  1. Touchez l’appli Paramètres.
  2. Touchez À propos du téléphone, tout en bas.
  3. Regardez le nom du modèle en haut (par exemple Galaxy S26 · SM-S942N).
  4. Touchez Informations sur le logiciel.
  5. Regardez la version de One UI (par exemple 9.0).

Sur certains modèles, le menu s’appelle ‘À propos de l’appareil’. Vous pouvez aussi taper ‘À propos du téléphone’ dans la recherche des Paramètres.

S’entraîner à ces étapes

Ce choix est facultatif. Il est enregistré seulement dans ce navigateur et nous ne devinons jamais votre modèle.
