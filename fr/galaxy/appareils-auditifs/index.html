Vérifier la compatibilité avec les appareils auditifs

Activez la compatibilité avec les appareils auditifs pour mieux entendre les appels.

Écrit pour Galaxy S26 · One UI 9 · Android 17. Les noms des menus peuvent différer sur d’autres modèles et versions.

  1. Étape 1 sur 6

    Touchez l’application ‘Paramètres’.

    Si elle n’est pas sur l’écran d’accueil, balayez vers le haut pour la trouver dans l’écran des applications.

  2. Étape 2 sur 6

    Touchez ‘Accessibilité’.

    Si vous ne le voyez pas, balayez vers le haut.

  3. Étape 3 sur 6

    Touchez ‘Améliorations de l’audition’.

    Si vous ne le voyez pas, balayez vers le haut.

  4. Étape 4 sur 6

    Touchez ‘Prise en charge des appareils auditifs’.

    Si vous ne le voyez pas, balayez vers le haut.

  5. Étape 5 sur 6

    Touchez l’interrupteur ‘Compatibilité avec les appareils auditifs’ pour l’activer.

    Les appels sont plus clairs avec un appareil auditif.

  6. Étape 6 sur 6

    Connectez les appareils auditifs Bluetooth dans le menu Bluetooth.

Bravo ! Vous avez terminé cette leçon. Suivante : Régler le toucher et le raccourci d’accessibilité
