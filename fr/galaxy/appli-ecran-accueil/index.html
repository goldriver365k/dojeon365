Mettre une appli sur l’écran d’accueil

Mettez sur l’écran d’accueil une appli de l’écran des applications.

  1. Étape 1 sur 3

    Balayez vers le haut sur l’écran d’accueil pour ouvrir l’écran des applications.

  2. Étape 2 sur 3

    Maintenez appuyée l’appli voulue.

  3. Étape 3 sur 3

    Touchez ‘Ajouter à l’accueil’.

Écrit pour Galaxy S26 · One UI 9 · Android 17. Les noms des menus peuvent différer sur d’autres modèles et versions.
