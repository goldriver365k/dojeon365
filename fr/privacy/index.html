Politique de confidentialité

DigiStep365 fonctionne sans compte. Nous ne demandons ni nom, ni e-mail, ni numéro de téléphone.

Ce qui est enregistré sur votre appareil

La taille du texte, votre avancement et le modèle de téléphone choisi sont enregistrés uniquement dans ce navigateur (stockage local). Ils ne nous sont jamais envoyés. Effacer les données du navigateur les supprime.

Statistiques

Si vous touchez « Accepter », Google Analytics 4 compte les visites pour savoir quelles leçons aident. Si vous touchez « Non merci », rien n’est chargé. Vous pouvez changer votre choix ci-dessous.

Boutons de partage

Les boutons de partage ouvrent KakaoTalk, Facebook ou WhatsApp uniquement quand vous les touchez. Nous ne leur transmettons aucune donnée ; ces services ont leurs propres politiques de confidentialité. Le code QR et « Copier le lien » fonctionnent dans votre navigateur.

Liens vers d’autres sites

Les leçons renvoient aux modes d’emploi et pages d’assistance officiels de Samsung. Ces sites ont leur propre politique de confidentialité.
