WhatsApp 사용법 관리 (해외 전용)

해외(19개 언어) 사이트용 WhatsApp 교육을 관리합니다. 영어가 기준이며, 실제 WhatsApp 앱과 대조해 검수·공개한 수업만 그 언어 사이트에 나옵니다. 국내(한국어) 사이트에는 나오지 않습니다.

언어별 진행률

사용 방법과 원칙
  1. 이미지: 교육용 카카오톡 계정(가상 이름·가상 대화)으로 실제 갤럭시에서 캡처한 화면만 올립니다. AI로 만든 화면·비슷하게 그린 화면은 쓰지 않습니다. 화면은 고치지 말고, 그림을 눌러 누를 곳(빨간 원)만 표시합니다.
  2. 개인정보: 실제 전화번호·계정·인증번호·비밀번호·결제 정보·실제 대화가 보이지 않는지 확인하고 단계마다 ‘개인정보 확인’을 체크합니다.
  3. 한 카드 = 한 동작. 설명은 짧고 쉽게 씁니다. ‘음성 안내’를 비우면 설명 문장을 읽어 줍니다.
  4. 버전: 카카오톡 앱 버전·안드로이드·One UI·갤럭시 모델·메뉴 경로·마지막 확인 날짜·검수자·공식 참고 자료를 적습니다. 업데이트로 화면이 바뀌면 ‘업데이트 필요’로 바꾸고 이미지를 교체합니다.
  5. 저장: 쓰기 권한(Contents: Read and write) 개인 액세스 토큰으로 GitHub에 저장하면 이미지와 data/kakaotalk/catalog.json이 커밋되고 1~3분 뒤 사이트에 반영됩니다. 토큰이 없으면 JSON을 내려받아 저장소에 넣습니다(이 경우 이미지는 images/kakaotalk/에 직접 넣어야 함).
