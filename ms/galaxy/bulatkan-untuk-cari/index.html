Mencari perkara di skrin

Cari sesuatu di skrin dengan membulatkannya menggunakan Bulatkan untuk Cari.

Ditulis untuk Galaxy S26 · One UI 9 · Android 17. Nama menu mungkin berbeza pada model dan versi lain.

  1. Langkah 1 daripada 3

    Sentuh dan tahan butang Utama di bawah skrin.

  2. Langkah 2 daripada 3

    Lukis bulatan dengan jari di sekeliling perkara yang ingin dicari.

  3. Langkah 3 daripada 3

    Baca hasil carian di bawah.

    Perlu tahu Bixby Vision tersedia pada siri Galaxy S25, S24 dan S23. S26 menggunakan cara ini (Bulatkan untuk Cari).
