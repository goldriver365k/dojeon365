Menghidupkan pembesar suara semasa panggilan

Hidupkan pembesar suara semasa panggilan untuk bercakap tanpa memegang telefon di telinga.

Ditulis untuk Galaxy S26 · One UI 9 · Android 17. Nama menu mungkin berbeza pada model dan versi lain.

  1. Langkah 1 daripada 3

    Buat atau terima panggilan.

  2. Langkah 2 daripada 3

    Ketik ‘Pembesar suara’.

    Anda boleh mendengar dan bercakap dengan telefon jauh dari telinga.

  3. Langkah 3 daripada 3

    Untuk mematikan, ketik ‘Pembesar suara’ sekali lagi.
