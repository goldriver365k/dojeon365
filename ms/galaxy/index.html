Mula-mula, cari model dan versi perisian telefon anda
  1. Ketik aplikasi Tetapan.
  2. Ketik Perihal telefon di paling bawah.
  3. Lihat nama model di atas (contohnya Galaxy S26 · SM-S942N).
  4. Ketik Maklumat perisian.
  5. Lihat versi One UI (contohnya 9.0).

Pada sesetengah model menu ini dinamakan ‘Perihal peranti’. Anda juga boleh menaip ‘Perihal telefon’ dalam carian Tetapan.
